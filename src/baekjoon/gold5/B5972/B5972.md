# 백준 5972 - 택배 배송

## 문제 설명
농부 현서가 헛간 1번에서 N번까지 이동할 때 소를 최소한으로 만나는 경로를 구하는 문제이다.
N개의 헛간과 M개의 양방향 도로가 주어지며, 각 도로마다 소의 수가 있다. 1번에서 N번 헛간까지의 최단 경로(소의 수 합이 최소)를 다익스트라로 구한다.

---

## 문제 풀이 과정
1번 노드에서 N번 노드까지의 최소 비용 경로를 구하는 전형적인 다익스트라 문제이다.

`d[]` 배열을 `Integer.MAX_VALUE`로 초기화한 뒤, 출발 노드 비용을 0으로 설정하고 PriorityQueue로 최소 비용 노드부터 탐색했다.
이미 더 짧은 경로로 방문한 노드는 `if(d[nodeB] < distance) continue;` 조건으로 스킵해 불필요한 탐색을 줄였다.
