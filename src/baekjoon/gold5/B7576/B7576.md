# 백준 7576 - 토마토

## 문제 설명
M×N 크기의 창고에 토마토가 저장되어 있다. 익은 토마토(1)는 인접한 익지 않은 토마토(0)를 하루에 하나씩 익게 만든다. 빈 칸(-1)은 토마토가 없다. 모든 토마토가 익는 최소 일수를 구하되, 불가능한 경우 -1을 출력한다.

---

## 문제 풀이 과정
처음부터 익은 토마토가 여러 개일 수 있으므로, 모든 익은 토마토를 큐에 넣고 동시에 BFS를 시작하는 **멀티 소스 BFS** 방식을 사용했다.

입력 단계에서 `box[r][c] == RIPE`인 좌표를 모두 `day=0`으로 큐에 넣은 뒤 탐색을 시작한다.
인접한 칸이 `UNRIPE`이면 `RIPE`로 갱신하고 `day+1`을 담아 큐에 추가하며, BFS 종료 후 마지막으로 꺼낸 `Position`의 `day` 값이 전체 소요 일수가 된다.
탐색 완료 후 `hasUnripeTomato()`로 0이 남아있는지 확인하고, 고립된 토마토가 존재하면 -1을 반환한다.

경계 체크는 `isInBounds()`로 분리했고, 큐는 `LinkedList` 대신 `ArrayDeque`를 사용해 불필요한 오버헤드를 줄였다.
