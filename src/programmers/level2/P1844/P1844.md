# 프로그래머스 1844 - 게임 맵 최단거리

## 문제 설명
NxM 크기의 게임 맵에서 (0,0)에서 출발해 (N-1, M-1)까지의 최단거리를 구하는 문제이다.
벽(0)은 통과할 수 없고, 도달할 수 없으면 -1을 반환한다.

-----------------------------------------------------

## 문제 풀이 과정

BFS로 풀었다. 큐에 현재 위치와 거리를 함께 저장하며 탐색했다.
벽이거나 이미 방문한 칸은 건너뛰고, 목적지에 도달하면 거리를 반환하고, 큐가 비어도 도달하지 못하면 -1을 반환했다.
시작 거리를 0이 아닌 1로 초기화해 출발 칸도 거리에 포함시켰다.
